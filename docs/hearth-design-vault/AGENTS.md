# Project Guide

This Obsidian vault explores a commercial 2–8 player game for friends and family. The current direction is a persistent, procedurally generated world with Minecraft-like freedom but a more inhabited, eventful, and responsive world. The aesthetic, camera, combat, progression, and technology are undecided.

## Working method

- Let the user choose questions in any order; the index does not assign a current or priority question.
- Record detailed exploration in the subject note. When the user accepts a conclusion, update its `Answer` section and overwrite that question's `Current answer summary` cell in `04 Production/Design Questions.md`.
- Keep possibilities and proposed directions out of the answer-summary column; use `Not decided` until the user accepts an answer.
- Keep the broader direction in `00 Start Here/00 Start Here.md` synchronized with finalized decisions.
- Treat possibilities as possibilities until the user chooses them.
- Add a subject note when its question is being explored; keep untouched questions only in the index.
- Keep discarded ideas out of the current direction; retain only a brief rejection when it prevents future confusion.
- Use research only to answer a concrete decision, and distinguish sourced facts from design judgment.
